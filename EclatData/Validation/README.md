# Éclat Validation

`--> ["what this is"]`

Small examiners for the wire's small rites.
Run them in studio; silence is success.

`--> ["examiners"]`

```text
Validation/
  HexValidation.server.luau     -- the hex translator, examined
  UplinkValidation.server.luau  -- retry · waitgroup · cookie sanitize · moods

  README.md
  StudioChecklist.md
```

`--> ["how"]`

1. Drop `Eclat` under `ServerStorage.Packages.Eclat`.
2. Drop a validation script under `ServerScriptService`.
3. Press play in studio. Read the output.
4. Every examiner prints `all verses true` or asserts loudly.

`--> ["covenant"]`

No examiner touches the network except the wire itself,
and none ever print a cookie.
